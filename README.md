# TCL Smart TV Website

## Project Overview
This project is a TCL Smart TV product website developed using
HTML5, CSS3, and JavaScript.

The website provides information about TCL Smart TVs, their
features, specifications, accessories, and ordering options.
It is designed with a simple, attractive, and responsive layout.

## Technologies Used
- HTML5 – Website structure and content.
- CSS3 – Styling, layout, and responsive design.
- JavaScript – Interactive features and user functionality.

## Main Features

1. **Navigation Bar**
   - Easy navigation between website sections.

2. **Product Features**
   - 4K Ultra HD Display.
   - Smart TV Features.
   - Powerful Sound.
   - Modern Design.

3. **Product Specifications**
   - TCL brand information.
   - Screen size and product details.
   - Price information.

4. **Product Information**
   - Read More / Read Less functionality.

5. **Product Categories**
   - All Products.
   - TVs.
   - Accessories.
   - Category filtering using JavaScript.

6. **Order Form**
   - Customer name, email, and address.
   - Payment method selection.
   - Installation and wall mounting options.

7. **JavaScript Functionality**
   - Birth-year input and age calculation.
   - Discount message based on calculated age.
   - Product category filtering.
   - Read More / Read Less button.

8. **Responsive Design**
   - Website layout adjusts to different screen sizes.

## How to Run the Project

1. Download or clone the project repository.
2. Open the project folder.
3. Locate the `index.html` file.
4. Open `index.html` in any web browser.
5. Explore the website and its interactive features.

## Project Purpose

The purpose of this assignment is to practice HTML,
CSS, and JavaScript concepts by developing a product-based
website with a responsive layout and interactive features.
